# fatihlovestosimplify

youtube'da yayınladığım videoların örnek kodları: [fatih loves to simplify](https://www.youtube.com/@fatihlovestosimplify)

## Motion Canvas

```sh
npm install
npm start
```

## Kod düzeni

- `npm run format`: kodları Prettier ile formatlar.
- `npm run lint`: ESLint kontrolü yapar; `npm run lint:fix` düzeltilebilenleri düzeltir.
- `npm run check`: format, lint ve TypeScript kontrollerini birlikte çalıştırır.

Bu komutlar kökteki Motion Canvas projesini kapsar. `ilke/` ve `ne ulan bu/` altındaki örnekler kendi npm projelerini kullanır. VS Code'da önerilen Prettier eklentisiyle dosyalar kaydederken formatlanır.
